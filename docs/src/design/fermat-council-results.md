# 20-agent 费马协作实验：纯内存邮箱实测

本轮按[协作议会方案](fermat-council-experiment.md)实际运行了两套独立
Codex/Pulsing 伴生实例：两个根 agent、十八个原生 subagent，共二十个不同线程。
邮箱和日志来自提交 `5e25df2d773c74e80d44e9268aebdde2ffd79095`，
Codex CLI 版本为 0.164.0。运行发生在同一台物理机器，不是物理多机验证。

结论：本轮负载下邮箱投递不是主要瓶颈，agent 启动、收信等待和报告收尾更慢。
实验形成了带未决前提的证明链，没有通过方案的全部阶段验收，
也没有产生新的费马大定理证明或完整形式化验证。

## 预算、身份与阶段偏差

- 总预算 600 秒，包括启动；二十个角色到第 **273.090 秒**才完成名册冻结，
  未达到计划的 45 秒目标，没有事后延长讨论时间。
- CLI JSON 流没有完整输出原生 spawn 信息。只读观察器通过根线程 ID、
  根 spawn 调用的 task_name、子会话 parent_thread_id/agent_path、
  actor 绑定和 READY 联合核对身份，没有依据自报角色直接授权。
- 第 600.001 秒请求停止，600.040 秒冻结进程树，600.071 秒收回根进程；
  截止后没有新邮件投递。随后只有离线导出，没有继续模型讨论。
- 四组均直接联系至少另外两个专业组；实际形成了模型修复、不可约性/p 处条件、
  特征桥接和符号归一化的动态面板。部分面板超过第 420 秒的计划截止。
- 三封正式仲裁在第 570.795–570.892 秒发送，略晚于 570 秒界限。
  这些偏差不追认为准时完成。

二十个角色都有实际发送和接收记录。37 封 unread 全部是封存阶段的 FINAL，

因此，投递成功不能解释为根角色已经消费并整合了全部最终报告。

## 论证产物与未决问题

仲裁对四个预置候选命题的结论为：

1. 拒绝“仅两两互素就推出 p 不整除 abc”：p=5、(a,b,c)=(5,2,3) 可反驳
   这个单前提蕴涵，不能冒称是费马方程反例。
2. 拒绝“仅半稳定就可以任意降层至 2”：讨论使用了具体半稳定曲线的判别式计算
   及剩余表示的局部障碍，但保留相关局部定理的外部输入边界。
3. 拒绝“等价引理必然循环”：整数奇偶命题提供了独立展开证明，再取逆否的例子；
   语义等价不等于实际证明依赖有环。
4. 按明示假设接受“可使用独立证明且假设匹配的黑箱”：逻辑许可不等于
   本轮已经认证某个具体定理的来源和适用性。

这些方向与截止后公开的预设标签一致，不是完整证明正确率，也不是有统计意义的
盲测成绩。审阅覆盖了协调者依赖图、仲裁和主要往返邮件，不替代独立数学审稿。

依赖图从线性概要改成合取依赖，避免把模性单独当成不可约性的来源；
面板区分了 Weierstrass 模型和最小模型，并指出仅有模 p 形式不能直接套用
复数 S₂(Γ₀(2))=0。剩余表示绝对不可约性、小素数范围、p|abc 分支的局部条件、
精确降层输出及来源适用性仍未核验。J0 未读完 p=3 的完整构造，保留独立认证未决。
部分版本映射未统一，依赖图仍是邮件中的文字版，不是机器校验的证明对象。

输入只有书目线索，没有完整可离线检查的定理原文，且禁止浏览；
未独立核源既是结果，也是本轮输入包的限制。最终分类是条件性证明链重建。

## 工件与验证边界

原始 actor JSONL、MCP 审计、二十个线程的可见对话、角色清单、候选论点、
仲裁邮件和统计保存在操作者本地归档，未上传仓库。隐藏推理和加密原生提示不导出。
已用本轮 270 个领取 token 检查工件，没有发现额外明文残留。
回放 CLI 结果与离线快照一致；99 个工件的 SHA-256 及 ZIP 校验通过，
运行目录没有 SQLite 文件，实验 agent 进程已停止。

公开报告不含原始数据或通用自动执行器，因此不能只凭此文独立复算全部统计。
测试是本次对当前内存实现的人工授权实测，不是 CI 自动调用模型，
也不是复用旧 SQLite 实验的数据。日志可回放不等于业务全部完成或支持故障恢复；
截止杀停的 actor 生命周期可能没有 stopped 事件。

下一步优先减少空轮询，验证有超时、可取消的等待式收信；改进启动方式和
最终报告消费窗口；提供可检查的定理输入包及可机检的版本化 claim/依赖。
这些是后续建议，本次没有实现或启动额外实验。
